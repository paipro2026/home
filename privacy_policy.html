隐私政策

最后更新日期：2026 年 1 月 1 日

派+（以下简称「本应用」或「我们」）非常重视您的隐私。本《隐私政策》将向您说明本应用如何处理您的信息， 以及您依法享有的权利。请在使用本应用前仔细阅读并充分理解本政策。

1. 我们收集的信息

本应用的所有核心功能均围绕「本地优先」设计，原则上不向服务器上传任何可识别的个人数据。具体包括：

  • 头像与昵称：仅存储于设备本地。
  • 正念日记：使用设备原生 Face ID / Touch ID 加密，仅存储于设备本地。
  • 地理围栏地点：由您自行设置，存储于设备本地，仅在到达指定区域时由系统本地计算并触发本地通知。
  • 冥想练习时长与统计：仅存储于设备本地，用于生成您的练习报告。

2. 我们如何使用信息

本应用使用上述信息的唯一目的是为您提供功能体验。我们不会将任何个人数据用于商业营销、用户画像或对外共享。

3. 信息的存储与保护

所有数据均存储在您的设备本地，并通过以下技术加以保护：

  • 正念日记受 Face ID / Touch ID 生物识别加密；
  • App 切换至后台或被关闭时，日记本会自动加锁；
  • 本应用不集成任何第三方数据分析或追踪 SDK。

4. 权限说明

  • 相册权限：仅用于您主动选择自定义头像，本应用不会读取您的其他照片。
  • 位置权限（始终）：用于实现「到达指定地点提醒」功能，仅在系统本地处理，不上传服务器。
  • 通知权限：用于推送您主动设置的提醒（如每日提醒、地理围栏到达提醒）。
  • 通讯录权限：仅在您主动使用「邀请好友」功能时读取，不上传也不存储。
  • Face ID / Touch ID：由系统提供生物识别校验，本应用不接触您的生物信息。

5. 您的权利

您可随时通过删除本应用以清除全部本地数据。如有任何隐私相关问题，欢迎通过以下方式联系我们：

📧 support@paipro.app

6. 政策的变更

我们可能根据法规更新或功能变化对本政策做出修订。任何重要变更都将在本应用内或官网公示。
